📥 Como importar no Figma com html.to.design

  1. Instale o plugin: No Figma, vá em Resources (Shift+I) → Procure "html.to.design" → Clique em Run
  2. Cole a URL:
    • Se estiver rodando localmente: http://localhost:[porta]/button-component-set.html
    • Ou faça deploy desta página e use a URL pública
  3. Configure as opções:
    • ✅ Import responsive breakpoints (se desejar)
    • ✅ Convert to Auto Layout (recomendado)
    • ✅ Import text styles
    • ✅ Import color styles
  4. Clique em "Import": O plugin irá converter todo o HTML/CSS em elementos do Figma
  5. Organize os componentes:
    • Selecione cada grupo de estados (Default, Hover, Active, etc.)
    • Selecione todos os botões de uma variante
    • Clique com botão direito → "Create component set"
    • Configure as propriedades: Variant, Size, State
  6. Publique na biblioteca: Menu superior → Ícone de livro → Publish
💡 Dica Pro: Após importar, agrupe os elementos por seção (Primary, Secondary, Ghost) e converta cada seção em um Component Set separado. Depois você pode organizá-los todos em um único Component Set master se preferir, ou manter separados para melhor organização.

⚡ Atalho: Use Cmd/Ctrl + Click para selecionar múltiplos botões de uma vez e criar o Component Set mais rapidamente.

🎨 Ajustes: O plugin preserva todos os estilos CSS (gradientes, sombras, bordas, etc.). Você pode precisar apenas ajustar o Auto Layout e criar as variantes após a importação.
