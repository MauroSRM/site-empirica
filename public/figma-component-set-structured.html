📥 Estrutura de Camadas

Cada botão já vem com 3 camadas organizadas:

  1. Layer 1: Background - Gradiente de fundo base (sempre visível)
  2. Layer 2: Overlay - Camada de sobreposição que desliza no hover
    • No estado Default: left: -100% e opacity: 0
    • No estado Hover: left: 0 e opacity: 1
  3. Layer 3: Text - Texto do botão (sempre por cima)
💡 Como usar no Figma:

1. Importe com html.to.design
2. As camadas já estarão nomeadas corretamente: "layer-background", "layer-overlay", "layer-text"
3. Renomeie para nomes mais simples: "Background", "Overlay", "Text"
4. Para prototipar: Default → Hover com "While hovering" + "Smart Animate" + 300ms
5. O Smart Animate irá animar automaticamente a posição X e opacity da Overlay!

⚡ Gradiente do Overlay Hover já corrigido: #082f62 → #024291 (conforme o anexo)
