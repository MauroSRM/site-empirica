💡 Observação Importante
A única diferença entre Default e Hover é a posição X e opacity da camada "Overlay". Todas as outras camadas permanecem EXATAMENTE iguais. Isso permite que o Smart Animate funcione perfeitamente.

📝 Passo a Passo no Figma

Criar o Frame do Botão Default
Crie um Frame de 240×48px chamado "Button/Primary/Default"
Adicionar Layer 1 - Background
Dentro do frame, adicione um retângulo que preencha todo o espaço (240×48px):
Nome: "Background" Fill: Linear Gradient 135° • Color 1: #071744 • Color 2: #0a2c68 Position: X=0, Y=0
Adicionar Layer 2 - Overlay (Estado Oculto)
Adicione outro retângulo do mesmo tamanho:
Nome: "Overlay" Fill: Linear Gradient 135° • Color 1: #1e40af • Color 2: #3b82f6 Position: X=-240, Y=0 Opacity: 0%
Importante: A posição X=-240 coloca a overlay completamente fora do frame à esquerda
Adicionar Layer 3 - Text
Adicione o texto:
Nome: "Text" Content: "Primary Button" Color: #f0f2f6 Font: Inter 15px / 600 Position: Centralizado (Auto Layout ou constraints)
Ativar Clip Content
Selecione o frame principal e ative "Clip content" para esconder a overlay quando estiver fora do frame
Duplicar para criar estado Hover
Duplique o frame e renomeie para "Button/Primary/Hover". Ajuste APENAS a layer "Overlay":
Nome: "Overlay" (mesmo nome!) Position: X=0, Y=0 Opacity: 100%
Configurar Protótipo
Selecione o botão "Default", vá em Prototype e configure:
Trigger: While hovering Action: Change to → Button/Primary/Hover Animation: Smart Animate Easing: Ease Out Duration: 300ms
🎯 Dica Crítica: Nomes das Camadas
Para o Smart Animate funcionar, as camadas devem ter EXATAMENTE o mesmo nome nos dois estados (Default e Hover). Se você nomear diferente, o Figma não conseguirá interpolar a animação.

✅ Certo vs Errado

✅ CORRETO
Default: └─ Background └─ Overlay (X=-240, Opacity=0%) └─ Text Hover: └─ Background └─ Overlay (X=0, Opacity=100%) └─ Text
Nomes idênticos = Smart Animate funciona!
❌ ERRADO
Default: └─ Background └─ Rectangle 1 └─ Text Hover: └─ Background └─ Rectangle 2 └─ Text Copy
Nomes diferentes = Fade simples (sem slide)
